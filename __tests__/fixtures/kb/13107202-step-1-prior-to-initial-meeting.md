## 2. Purpose

*The purpose of this procedure is to capture new prospective leads, schedule them for appointment with the right adviser, and provide the necessary documents and forms that enable them to progress to the initial meeting stage.*

## 3. Scope

*This procedure covers all steps leading up to the initial meeting. It does not include*

*Everything required before starting. Cover each category that applies:*

- **Systems / tools:** *Calendly, Outlook, Twilio*

## 7. Procedure — step by step

| # | Description | When it happens | Who does it | System / tool | Expected result |
| --- | --- | --- | --- | --- | --- |
| **Stage 1 - Prior to Initial Meeting** |  |  |  |  |  |
| 1 | ***Appointment Booked via Calendly*** | *Prior to Initial Meeting* | *Prospect or Client Services* | *Calendly* | *Appointment scheduled in Advisors diary* |
|  | A prospect can organise an appoint from two options.<br>1) via the website on the home page using the make booking page or;<br>2) Direct contact with Q Wealth and client services making the booking using Calendly or the advisers outlook calendar. *The preferred method is directly on the Calendly platform.* <br><br>Each Adviser has a personal appointments link - <br>- **Simone Du Chesne:** (to be added)<br>- **Huy Luu:** (to be added)<br>- **Chris Du Chesne:** (to be added)<br>The general booking page is at [qwealth.com.au](http://qwealth.com.au) |  |  |  |  |
| 2 | ***Client added into CRM as Prospect*** | *When the appointment is made.* | *Automated by Calendly* | *Calendly* | *Client record is created and visible.* |
|  | Calendly is integrated with the Q Wealth CRM. When the appointment is made, this triggers Calendly to add the prospect into the CRM database. Asking Claude for a list of the most recent prospects will determine if the newly added prospect exists. |  |  |  |  |
| 3 | ***Confirmation to Prospect and request to complete Snapshot.*** | *After appointment is made.* | *Automated by Calendly* | *Calendly* | *Email Confirmation and email log in Calendly.* |
|  | An email is triggered by Calendly which goes direct to the prospect to confirm the appointment and add it into their calendar. This will include the Teams link if the meeting is online. Within the email is a request to complete the Snapshot form. This Snapshot form is directly integrated to the MyProsperity Portal. |  |  |  |  |
| 4. | **Provision of FSG and Privacy Policy** | After appointment is made | *Automated by Calendly* | Calendly | Email Confirmation and email log in Calendly |
|  | Email is sent to the prospect that includes a link to the Financial Services Guide and the Privacy Policy. These are both public documents. Within the email there is also reference to these documents within the MyProsperity App. |  |  |  |  |
| 5. | **Set client folder up in Sharepoint** | After appointment is made. | *Client Services* | Sharepoint | The folder is visible in the directory and accessible. |
|  | A member of client services creates a folder in sharepoint that becomes the repository for raw files related to that particular prospect. Go to Group work \> WIP. Add a folder with the following name structure *(Last name, first name)*. Then proceed to add any subfolders that are required. |  |  |  |  |
| 6. | **Meeting reminder and confirmation** | 1 day before meeting | Automated by Calendly | Calendly + Twillio | Email confirmation is sent to both prospect and adviser. |
|  | Meeting reminder is emailed or SMS from Calendly to the prospect letting them know their appointment is ‘tomorrow’. This is to ensure the prospect does not forget the appointment. At the same time a reminder is provided to the adviser, so the adviser can be adequately prepared for the meeting. |  |  |  |  |
| 7. | **Prepare the first meeting pack** | at least 1 day before the first meeting | Client Services | N/A | Checklist is completed for the first meeting pack. |
|  | The Client Services team prepares the first meeting pack for the adviser to present in the meeting.<br>• Risk Profile<br>• Client Snapshot<br>• TPA<br>• Financial Services Guide (FSG)<br>• Privacy Policy<br>• Vanguard Index |  |  |  |  |

> **Common pitfalls / warnings:**  There are no pitfalls identified at this stage.
